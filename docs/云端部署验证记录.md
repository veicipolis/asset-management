## 缺陷：初始化中文数据乱码

### 现象
资产名称、类别、位置以及部门、角色和用户显示名乱码。
HEX 查询确认部分字段已存储为乱码字节，并非仅终端显示异常。
修复过程中还发现部分字段为空。

### 排查
本地 SQL 文件为有效 UTF-8，中文种子内容正常；
脚本原先未显式设置连接字符集。
具体发生错误解码的导入环节未完全复现。

### 修复
1. 使用已核对的 UTF-8 十六进制字面量恢复演示名称。
2. 保留原有 ID、关联关系、账号密码及角色绑定。
3. 在五份初始化脚本开头增加 SET NAMES utf8mb4。
4. 手动连接 MySQL 时显式指定 --default-character-set=utf8mb4。
5. 将修正后的脚本上传服务器，未重跑已有数据库的初始化脚本。

### 验证与限制
现有数据修复后查询正常，网页登录及中文显示复核完成。
修正脚本在全新空数据库中的初始化回归尚未执行。
云端核心业务流程验收待完成。
