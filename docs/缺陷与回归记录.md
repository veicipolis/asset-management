# 缺陷与回归记录

关联工作项：[4.7]。

本记录依据实际排查过程事后整理，不虚构发现日期。
业务缺陷、测试代码问题及部署配置问题分别标明。

## DEF-001 云端初始化中文乱码

- 类型：部署与数据初始化问题。
- 现象：资产名称、类别、位置以及部门、角色和用户显示名乱码。
- 排查：HEX查询证实存储字节异常；本地SQL文件为有效UTF-8，
  原脚本未显式设置连接字符集。
- 原因边界：未完整复现最初发生错误解码的具体环节。
- 修复：
    1. 使用正确UTF-8十六进制字面量恢复已损坏的演示字段。
    2. 初始化脚本增加SET NAMES utf8mb4。
    3. 手动MySQL连接明确指定utf8mb4。
- 回归：修复后查询正常；前四份初始化脚本在隔离空库中执行成功，
  部门、资产名称和位置的HEX值正确。
- 状态：已修复并完成上述范围的回归。
- 依据：《云端部署验证记录.md》。

## DEF-002 云端演示账号未提交事务

- 类型：部署操作问题。
- 现象：网页登录失败，查询app_user未找到目标账号。
- 原因：初始化脚本不自动提交，操作时遗漏COMMIT。
- 修复：重新初始化，核对账号与角色后显式提交事务。
- 回归：账号保存成功，网页登录及云端完整业务流程通过。
- 预防：部署说明要求提交后重新连接数据库确认账号持久化。
- 状态：已解决。

## DEF-003 回滚测试的异常类型断言错误

- 类型：自动化测试代码问题，不是业务回滚缺陷。
- 现象：测试预期IllegalStateException，
  实际抛出InvalidDataAccessApiUsageException。
- 原因：Repository异常转换机制包装了模拟异常。
- 修复：断言外层异常类型，并校验其cause为
  IllegalStateException且消息为“模拟日志写入失败”。
- 回归：四组并发与事务测试全部通过；
  资产与申请状态、版本恢复原值，无残留领用记录及成功日志。
- 状态：已修复并回归通过。

## DEF-004 测试运行配置缺少数据库密码

- 类型：本地测试环境配置问题。
- 现象：部分测试无法建立JDBC连接或加载ApplicationContext。
- 已确认原因：曾仅为Repository测试运行配置设置密码，
  其他测试配置遗漏测试库密码环境变量。
- 修复：为对应JUnit运行配置设置ASSET_TEST_DB_PASSWORD。
- 回归：应用上下文及Repository测试通过，
  后续并发事务测试与查询性能测试完成。
- 预防：新建JUnit运行配置时检查测试profile和密码环境变量。
- 状态：已解决。
- 限制：不将所有JDBC连接失败都归因于密码，仍需检查具体异常。
