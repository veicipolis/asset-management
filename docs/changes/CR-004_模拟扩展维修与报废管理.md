# CR-004 模拟扩展维修与报废管理

## 基本信息

- 记录日期：以本次 Git 提交日期为准。
- 决策人：本人，承担课程模拟项目经理角色。
- 类型：模拟项目范围扩展。
- 状态：同意纳入规划；未实施，估算及排期待评估。

## 变更原因

当前核心系统已覆盖资产建档、领用、审批、发放和归还。
为完善固定资产生命周期规划，将原扩展范围中的维修、
报废管理细化为后续工作包。

本次用于课程模拟管理，不增加当前软件的实现范围。

## 变更内容

1. 维修管理：报修登记、维修受理、维修结果登记与恢复使用。
2. 报废管理：报废申请、审批、执行及审计。
3. 补充状态规则、权限约束、验收条件及测试计划。

## 影响分析

- 范围：新增两个模拟功能模块。
- 设计：需评估维修单、报废单及其与资产的关联。
- 安全：需防止越权、重复执行和非法资产状态转换。
- 数据：不得删除历史领用、维修或报废记录。
- 工时、成本、资源及排期：本轮未评估。
- 当前632小时、80,075元人工成本及88,118.70元暂估总预算不变。
- 不能据此认定课程“开发成本十万以上”要求已满足。

## 处理决定

本次仅批准编写模拟规划文档。
不修改现有业务代码、数据库、Project计划或预算。
后续实施须完成详细设计、估算及排期评审。

本决定不代表指导教师审批。

## 验收与状态

本次文档交付要求：
- 明确维修、报废的功能边界。
- 明确角色、状态规则和拟定验收条件。
- 明确标注未实现、未测试。

文档完成不代表功能完成，不得关闭相应开发工作项。
