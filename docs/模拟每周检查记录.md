## 3. 跟踪规则

- 发现问题时记录责任角色、处理措施和复核点。
- 尚未验证的事项不得写为通过。
- 实际测试结论引用《业务与权限测试记录》
  《缺陷与回归记录》和《云端部署验证记录》。
- 本表的假设问题不直接认定为实际发生过的缺陷。
- 当前未建立正式基准，不宣称本表证明进度或成本没有偏差。
- 真实提交、发布及Issue状态按实际发生时间维护。
