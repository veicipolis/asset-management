## 二、测试前准备

1. 确认 MySQL 和应用正常运行。
2. 确认 employee 与 approver 属于同一部门。
3. 确认 employee2 属于另一个部门。
4. 使用普通窗口与无痕窗口区分员工和管理员会话。
5. 使用专用测试资产，不修改已有历史业务数据。
6. 不在文档、截图或日志中记录密码、密码哈希及会话令牌。
