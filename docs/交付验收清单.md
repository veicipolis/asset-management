## 2. 交付内容

- Java源码、Thymeleaf模板及Maven配置。
- 数据库结构、基础数据和账号初始化脚本。
- Dockerfile、Compose配置及部署运行说明。
- 需求、权限、状态、类图与请求接口文档。
- 测试、性能测量、缺陷及云端验证记录。

密码、.env、数据库备份和IDE私有配置不作为Git交付内容。
发布JAR及其校验值另行登记。

## 3. 已知限制

- 课程暂估预算未达到十万元以上。
- 正式基准、基准对比及同口径工时偏差未完成。
- 模拟检查记录、成员对应关系、共享他人代码等管理要求，
  仍需逐项核实，不能由核心软件通过推定满足。
- 仅通过SSH隧道访问，未配置公网HTTPS。
- 性能数据为本地Repository串行查询结果。
- 未验证一万用户并发或云端最大承载能力。
- 备份仍位于同一服务器。
- 维修、报废仅有模拟规划，未实现、未测试。
- 最终实验报告与报告截图不属于本轮交付。
