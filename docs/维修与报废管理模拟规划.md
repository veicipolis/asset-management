## 3. 维修管理

### 拟定流程

报修登记 → 管理员受理 → 进入维修 → 登记结果 → 恢复闲置。

### 拟定规则

- 员工仅可对本人有效领用的资产提交报修。
- 资产管理员可登记闲置资产报修。
- 报修本身不直接结束领用或改变资产状态。
- 在用资产应先完成归还接收，再进入维修。
- 进入维修时要求资产为 IDLE，且无有效领用。
- 维修资产不能申请领用或发放。
- 维修完成后由管理员确认恢复 IDLE。
- 无法修复时另行发起报废流程，不直接删除资产。

### 拟定验收条件

- 非本人资产报修被拒绝。
- 同一资产不能重复进入有效维修流程。
- 维修期间的领用申请与发放被拒绝。
- 维修结束的状态变更和日志同事务提交。
- 旧页面重复提交被拦截。

## 4. 报废管理

### 拟定流程

资产管理员提出报废 → 授权审批人审核 → 管理员执行报废。

报废审批权限须在实施前细化到权限矩阵；
不得直接推定现有部门领用审批权限包含报废审批。

### 拟定规则

- 申请人不得审批本人提出的报废申请。
- 资产存在有效领用或未结束业务时，不允许执行报废。
- 执行前必须完成维修等相关业务的关闭与核对。
- 执行报废时，资产仅允许从 IDLE 或 MAINTENANCE 转为 SCRAPPED。
- 报废后禁止领用、发放及普通页面恢复闲置。
- 保留原资产编号、业务历史、审批意见及执行日志。
- 重复执行不得产生重复变更或成功日志。

### 拟定验收条件

- 越权、自审批及非法状态转换被拒绝。
- 审批不通过时不改变资产状态。
- 执行前重新检查关联业务及版本。
- 报废状态与日志原子提交，失败时整体回滚。
